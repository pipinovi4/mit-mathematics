# MIT Mathematics

My self-study repository for mathematics courses from MIT OpenCourseWare.

The goal is not just to complete the lectures, but to understand the material, solve the problems independently, and build a strong mathematical foundation.

## Courses

- [ ] 18.01SC — Single Variable Calculus
- [ ] 18.06 — Linear Algebra
- [ ] 6.042J — Mathematics for Computer Science
- [ ] 18.02SC — Multivariable Calculus
- [ ] Probability & Statistics

## Structure

Each course contains:

- lecture notes
- definitions and key ideas
- worked examples
- problem solutions
- mistakes and corrections
- exam attempts

## Learning approach

For each topic:

1. Watch the lecture and take short notes.
2. Explain the main idea in my own words.
3. Solve exercises without looking at the solution.
4. Review mistakes and write down what went wrong.
5. Move on only when the core idea makes sense.
